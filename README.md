# python-refresher

Python fundamentals practice, built while learning backend development.

## Contents
- `basics.py` — core functions: sum, reverse, highest score, multiples, f-strings, file reading with error handling
- `advanced.py` — list comprehensions, *args, **kwargs, module imports
- `main.py` — demonstrates importing and calling functions across modules
- `wordcount.py` — CLI script that reads a .txt file and prints a word count summary
